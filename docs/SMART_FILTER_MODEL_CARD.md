# ORION Physics-Supervised Smart Filter

## Intended use and label

The classifier predicts whether ORION research Pc reaches `1e-4` under configured covariance/HBR scenarios. Labels are generated by the physics estimator, not observed collisions. Classifier output supports triage only. An independent safety guard retains events inside the configured miss-distance threshold, with any scenario at or above the Pc threshold, or with invalid/uncertain inputs.

## Training data and leakage-controlled split

Uses 1,416 physics-labelled scenario variants from 118 parent events in saved CelesTrak job `08c33d64c8d34ddfb6838a565d3c0db3`. Cross-job encounter grouping reduces them to 62 independent physical groups. The fixed-seed `20261024` split keeps each full encounter group in one partition: train 43 groups / 75 parents / 900 variants; validation 9 / 20 / 240; test 10 / 23 / 276. Model version `2.1.0`; dataset `orion-collision-scenarios-v3`; target significant iff generated research Pc is at least `1e-4`.

## Held-out test

Class order: insignificant, significant. Confusion matrix (true rows, predicted columns): `[[176,8],[10,82]]`. Accuracy `0.93478`, macro F1 `0.92623`, significant precision `0.91111`, significant recall `0.89130`, with 10 false negatives among 92 significant variants. Majority baseline accuracy was `0.66667`, macro F1 `0.40000`, and 92 false negatives. Deterministic 1 km miss-distance baseline accuracy was `0.42029`, macro F1 `0.38283`, significant recall `1.00000`, and zero false negatives; it retains many insignificant events. The classifier beat both baselines on macro F1 and beat the majority baseline on false negatives, so the artifact is enabled for triage. The 10 classifier false negatives make the independent safety guard essential.

The runtime guard is evaluated independently of classifier output and retains a pair if any configured research-Pc scenario reaches the significant threshold, if it is within the miss-distance threshold, or if an assessment is invalid or uncertain. It is not counted as part of classifier recall.

## Artifact and limitations

Artifact: `backend/app/ai/artifacts/orion_smart_filter_classifier.joblib`, version `2.1.0`. Its sidecar records hash, schema, encounter-group split, counts, held-out metrics, baselines, and guard policy. Training is offline through `scripts/retrain_all.ps1`; API requests load the saved artifact only. Metrics describe physics proxy labels from 10 test encounter groups / 23 parent events, not observed collision outcomes. Scenario variants are correlated and do not increase independent sample size. Classifier vote fractions are not calibrated probabilities.
