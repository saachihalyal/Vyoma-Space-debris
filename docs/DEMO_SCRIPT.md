## Honest limitations

- The restored snapshot finished partial, with 109 rows; it is not a fresh or complete catalog scan.
- Model training labels are generated by ORION's assumed physics, not observed collision outcomes; the Pc surrogate approximates the same formula.
- Covariance, hard-body radius, and independence assumptions are simplified; cross-object covariance and TLE-epoch covariance propagation are absent.
- Smart Filter is assisted by an independent deterministic guard; a classifier result is not a probability of collision.
- Maneuver search uses bounded two-body propagation and idealized fuel assumptions; it omits perturbations, execution errors, and feasibility checks.
- Globe view is a catalog visualization, and upload results are isolated reference calculations.
- No manual browser click-through or PDF visual inspection was performed for this final pass; automated tests and build do not establish UI behavior on a live browser.
